# UI 元素记录

本文档记录站点中所有添加的 UI 元素的位置、作用与交互逻辑。

---

## 全局

- **顶部强调条**：页面最顶部 3px 琥珀色渐变条（`BaseLayout`），固定定位。
- **背景**：深色径向渐变 + 极弱噪点层（`global.css`），营造层次感。

## 全局布局

### Header（顶部导航）

- **位置**：所有页面顶部，`src/components/Header.astro`
- **作用**：站点名称（链接到首页）、主导航（首页、项目、作品、博客、关于）
- **样式**：半透明背景 + 毛玻璃（backdrop-filter），Logo 字重 800、略紧字距；导航链接悬停时底部 2px 琥珀下划线动画。
- **交互**：
  - 桌面端：导航链接横排，悬停显示下划线，点击跳转
  - 移动端（≤768px）：导航默认收起，汉堡按钮展开/收起（`aria-hidden` / `aria-expanded`）

### Footer（页脚）

- **位置**：所有页面底部，`src/components/Footer.astro`
- **作用**：完整导航链接（首页、项目、作品、博客、关于）与版权
- **交互**：链接悬停强调色高亮

## 首页

### Hero（首屏）

- **位置**：首页顶部，`src/pages/index.astro`
- **作用**：大标题「个人网站」、副标题「项目展示 · 作品集 · 技术博客」、底部短琥珀渐变装饰线
- **样式**：标题响应式字号（clamp）、字重 800、负字距；副标题略加字距；装饰线 3rem 宽、4px 高
- **动效**：首屏 `fadeInUp` 入场

### 三块内容区（SectionBlock）

- **位置**：首页中部，依次为「项目」「作品」「博客」
- **作用**：每块展示该分类下的若干条摘要（Card），底部「查看全部」链到对应列表页
- **样式**：区块标题带底部琥珀色粗线（2px），与正文区分
- **动效**：三块依次错落入场（`animation-delay`）

### Card（卡片）

- **位置**：首页三块内、项目/作品/博客列表
- **作用**：展示单条标题与描述，点击整卡跳转详情
- **样式**：深色卡片背景、圆角、悬停左侧 4px 琥珀竖条展开、右上角箭头出现、轻微上浮与阴影加深
- **交互**：悬停时左侧竖条动画、卡片上移 4px、阴影增强、箭头显示

- **位置**：`src/pages/projects/index.astro`
- **作用**：以卡片网格展示所有项目，按 `order` 排序

### 作品列表（/works/）

- **位置**：`src/pages/works/index.astro`
- **作用**：以卡片网格展示所有作品，按 `order` 排序

### 博客列表（/blog/）

- **位置**：`src/pages/blog/index.astro`
- **作用**：以卡片网格展示所有博客，按发布时间倒序

## 详情页

### 项目详情（/projects/[slug]/）

- **位置**：`src/pages/projects/[slug].astro`
- **作用**：展示单个项目的标题、描述、链接（若有）、正文（Markdown 渲染）

### 作品详情（/works/[slug]/）

- **位置**：`src/pages/works/[slug].astro`
- **作用**：展示单件作品的标题、描述、正文（Markdown 渲染）

### 博客详情（/blog/[slug]/）

- **位置**：`src/pages/blog/[slug].astro`
- **作用**：展示单篇博客的标题、发布日期、标签、正文（Markdown 渲染）
