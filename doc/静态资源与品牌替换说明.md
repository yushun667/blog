# 静态资源与品牌替换说明

所有图标与 LOGO 的引用路径集中在 **`src/config/site.js`** 与 **`index.html`** 中。替换时按下列说明操作即可。

## 1. 站点 LOGO

| 项目 | 说明 |
|------|------|
| **用途** | 站点头部、首页品牌区 |
| **文件路径** | `public/logo.svg`（或 `public/logo.png`） |
| **推荐规格** | SVG 优先；PNG 建议 2x（如 128×128） |
| **替换步骤** | 覆盖 `public/logo.svg`，保持文件名不变。若改用 PNG 或更名，需同步修改 `src/config/site.js` 中的 `logoPath` 及引用该常量的组件（如 `src/components/Header.jsx`）。 |

## 2. Favicon

| 项目 | 说明 |
|------|------|
| **用途** | 浏览器标签页图标 |
| **文件路径** | `public/favicon.svg`（或 `public/favicon.ico`） |
| **推荐规格** | 单 SVG，或 ico 多尺寸（16/32/48） |
| **替换步骤** | 覆盖 `public/favicon.svg`。若改用 ico 或更名，需同步修改 `index.html` 中 `<link rel="icon" ... href="...">` 的路径。 |

## 3. Apple Touch Icon

| 项目 | 说明 |
|------|------|
| **用途** | 添加到主屏、分享缩略图 |
| **文件路径** | `public/apple-touch-icon.png` |
| **推荐规格** | 180×180 px |
| **替换步骤** | 将 180×180 的 PNG 放入 `public/apple-touch-icon.png`。若路径变更，需修改 `index.html` 中 `<link rel="apple-touch-icon" href="...">`。当前未提供占位文件，为可选资源。 |

## 4. 关于页头像

| 项目 | 说明 |
|------|------|
| **用途** | 关于页个人照片或品牌图 |
| **文件路径** | `public/avatar.svg`（当前；可改为 `public/avatar.jpg`） |
| **推荐规格** | 1:1，建议 400×400 以上 |
| **替换步骤** | 覆盖 `public/avatar.svg`。若改用 jpg 或更名，需修改 `src/config/site.js` 中的 `avatarPath`。 |

## 5. 社交/功能图标

| 项目 | 说明 |
|------|------|
| **用途** | 导航、页脚、链接（如 GitHub、邮箱） |
| **文件路径** | 可在 `public/icons/` 下按用途命名（如 `icon-github.svg`），或使用图标库 |
| **推荐规格** | SVG，单色或双色以适配主题 |
| **替换步骤** | 替换 `public/icons/` 内对应文件；若改用图标库，需在代码中更新引用并在本说明中注明库名与用法。 |

## 构建与生效

- 以上资源均在构建时被复制到 `dist/`，**无需重新构建即可生效**的只有未经过 Vite 处理的 `public/` 下文件（构建会直接拷贝）。替换后执行一次 `npm run build` 并重新部署，即可在线上看到更新。
