# 操作手册

## 项目说明

个人网站：博客、项目展示、作品展示。技术栈为 React + Vite，构建为静态站点，可部署至 GitHub Pages。

## 本地运行

```bash
# 安装依赖
npm install

# 生成博客数据（posts.json），再启动开发服务器
npm run build   # 会先执行 prebuild 生成 src/data/posts.json
npm run dev    # 开发模式，默认 http://localhost:5173
```

开发时若修改了 `src/content/posts/*.md`，需重新执行 `npm run build` 或直接运行 `node scripts/generate-posts.js` 以更新 `src/data/posts.json`，否则博客列表与文章内容不会更新。

## 构建与预览

```bash
npm run build   # 输出到 dist/
npm run preview # 预览 dist（默认带 base /blog/）
```

## 目录说明

| 目录/文件 | 说明 |
|-----------|------|
| `src/content/posts/` | 博客 Markdown 文章（frontmatter：title、date、summary、tags） |
| `src/data/` | 构建用数据：posts.json（脚本生成）、projects.json、works.json（可手编） |
| `scripts/generate-posts.js` | 构建前脚本，扫描 posts 生成 posts.json |
| `public/` | 静态资源：logo、favicon、头像等，见《静态资源与品牌替换说明》 |
| `src/config/site.js` | 站点常量（basePath、logo 路径等） |
| `src/pages/` | 页面组件；`src/components/` 为布局与通用组件 |

## 部署到 GitHub Pages

1. 推送代码到 GitHub 仓库（如 `yushun667/blog`）。
2. 仓库使用**官方 GitHub Actions 部署**：推送 `main` 后自动执行构建，并上传 artifact，由 `deploy-pages` 部署。
3. **必须**在仓库 **Settings → Pages**（**设置 → 页面**）中：
   - **Source** 选 **GitHub Actions**（用 Actions 部署，不要选 “Deploy from a branch”）；
   - 保存后等待 1～2 分钟。
4. 打开站点地址：**https://yushun667.github.io/blog/**（或 **https://yushun667.github.io/blog/#/**）。

若仍 404，请确认：① Settings → Pages 的 Source 为 **GitHub Actions**；② Actions 里 “Deploy to GitHub Pages” 两个 job（build、deploy）均为绿色。

图标与 LOGO 的替换方式见 `doc/静态资源与品牌替换说明.md`。
