# 操作手册

## 本地开发

1. **克隆与安装**
   - 克隆仓库后进入项目目录，执行：`npm install`
   - 依赖安装完成后执行：`npm run dev`
   - 在浏览器打开终端提示的本地地址（如 `http://localhost:4321`）进行预览

2. **构建**
   - 执行：`npm run build`
   - 静态文件将输出到 `dist/` 目录

3. **本地预览构建结果**
   - 执行：`npm run preview`
   - 使用构建后的 `dist/` 进行本地预览

## 内容维护

### 博客

- 在 `src/content/blog/` 下新建 `.md` 文件即可添加文章
- 每篇需在开头写 frontmatter，例如：
  ```yaml
  ---
  title: 文章标题
  description: 简短摘要
  pubDate: 2025-03-16
  tags: ["标签1", "标签2"]
  ---
  ```
- 正文使用 Markdown 书写，保存后重新 `npm run build` 或 push 后由 GitHub Actions 自动发布

### 项目

- 在 `src/content/projects/` 下新建 `.md` 文件
- frontmatter 示例：`title`、`description`、`link`（可选）、`tech`（数组，可选）、`order`（数字，用于排序）

### 作品

- 在 `src/content/works/` 下新建 `.md` 文件
- frontmatter 示例：`title`、`description`、`image`（可选）、`link`（可选）、`order`（可选）

## 部署（GitHub Pages）

1. **仓库设置**
   - 在 GitHub 仓库 **Settings → Pages** 中，将 **Build and deployment → Source** 选为 **GitHub Actions**

2. **发布**
   - 将代码 push 到 `main` 分支后，会自动触发 `.github/workflows/deploy.yml`
   - 工作流会执行 `npm ci`、`npm run build`，并将 `dist/` 部署到 GitHub Pages

3. **站点地址**
   - 若仓库名为 `用户名.github.io`，站点根地址为 `https://用户名.github.io`
   - 若仓库名为其他（如 `blog`），需在 `astro.config.mjs` 中设置 `base: '/blog/'`，站点地址为 `https://用户名.github.io/blog/`
